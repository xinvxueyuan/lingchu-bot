## Page transitions (View Transitions)

The previous documentation site carried a custom View Transitions layer for cross-page navigation and locale switches. During the Astro Starlight migration, that Next-specific layer is intentionally removed from the core documentation build.

## Current status

Starlight handles navigation, sidebar links, breadcrumbs, and locale switching through its built-in routing and UI. The first migration keeps this behavior simple and stable instead of recreating the old custom transition system.

If animated transitions return later, implement them as an Astro-compatible enhancement around Starlight pages and keep these requirements:

- Navigation must work without JavaScript and without `document.startViewTransition`.
- Motion must respect `@media (prefers-reduced-motion: reduce)`.
- Shared-element names must be scoped so ordinary doc-to-doc navigation cannot leave detached transition snapshots.
- Locale switching should preserve Starlight's generated locale URLs and search/index behavior.
