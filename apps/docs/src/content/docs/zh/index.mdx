成员管理              # 成员管理子菜单

重启协议端            # 重启 OneBot V11 协议端

## 当前能力

<ul class="hero-features">
  <li>
    <b>NoneBot2 核心</b>
    <span>插件入口，声明本地插件目录与适配器。</span>
  </li>
  <li>
    <b>QQ 群管理</b>
    <span>禁言、成员管理、群公告、踢人与群资料设置。</span>
  </li>
  <li>
    <b>OneBot V11 默认</b>
    <span>同一时间只启用一个适配器；Milky、QQ、OneBot V12 已弃用并移除。</span>
  </li>
  <li>
    <b>消息存储</b>
    <span>可选的事件、处理状态、生命周期与 API 调用摘要记录。</span>
  </li>
  <li>
    <b>TOML + ORM</b>
    <span>localstore 路径管理与跨 SQLite / PostgreSQL / MySQL / MariaDB 的异步 CRUD 辅助。</span>
  </li>
  <li>
    <b>i18n 运行时</b>
    <span>gettext / Babel 目录，覆盖 `zh_CN` 与 `en_US`。</span>
  </li>
  <li>
    <b>开发者工具</b>
    <span>prek 钩子、测试与 CI 检查流程。</span>
  </li>
  <li>
    <b>扩展空间</b>
    <span>为后续跨平台与非群管理功能预留。</span>
  </li>
</ul>

<Aside type="caution" title="项目状态">

本项目仍处于 pre-alpha / development 阶段。当前代码、配置、命令行为和文档都可能继续调整，请不要把现有接口视为稳定生产接口。

</Aside>
