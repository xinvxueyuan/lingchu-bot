通过现有 NoneBot ASGI 应用上受 OAuth 保护的 MCP v1 资源服务器，向外部 Agent 暴露 Lingchu Bot 的消息与 Bot 列表。该服务器默认关闭，不会充当授权服务器，也不会公开任意适配器 API。

## 前置条件

- 一个 OAuth 授权服务器，签发 RS256 或 ES256 JWT，并发布 JWKS 端点。
- 一个反向代理，在公网终止 TLS，仅转发配置好的路由到 Bot。
- 一个至少包含 32 个 UTF-8 字节的环境变量，用于游标加密。

## 启用服务器

首次启动会在插件配置目录创建 `mcp-server.toml`。所有安全字段就绪后，再将 `enabled = true` 打开：

```toml title="mcp-server.toml"
enabled = true
route = "/mcp"
issuer = "https://id.example.com/"
audience = "https://bot.example.com/mcp"
jwks_url = "https://id.example.com/.well-known/jwks.json"
identity_kind = "subject"
cursor_secret_env = "LINGCHU_MCP_CURSOR_SECRET"
read_rate_per_minute = 120
send_rate_per_minute = 20
conversation_send_rate_per_minute = 6
principal_concurrency = 8
conversation_write_concurrency = 2
max_page_size = 200
```

<Aside type="caution" title="不要把密钥写入 TOML">

`cursor_secret_env` 填写的是环境变量**名称**，不是密钥本身。请在环境中将 `LINGCHU_MCP_CURSOR_SECRET` 设置为至少 32 个 UTF-8 字节的值。修改文件后重启 Bot。启用状态下缺少必需设置时会拒绝启动。

</Aside>

## 授权 Principal 与 Grant

每条 principal 和 resource grant 都通过仓库根目录的 CLI 以一个事务提交：

```bash
uv run python scripts/mcp_admin.py principal-create \
  --principal-id deploy-agent --issuer https://id.example.com/ \
  --identity-kind subject --identity-value oauth-subject-123 \
  --display-name "Deployment agent"

uv run python scripts/mcp_admin.py grant-create \
  --grant-id deploy-agent-group-100 --principal-id deploy-agent \
  --platform qq --adapter '~onebot.v11' --protocol default \
  --bot-id 123456789 --conversation-type group \
  --conversation-id 100000001
```

其他管理命令包括 `principal-enable`、`principal-disable`、`grant-revoke` 和 `grant-list`。标识必须精确匹配，拒绝通配符。

## JWT 校验如何工作

JWT 必须通过配置的 HTTPS JWKS 端点完成 RS256 或 ES256 验签。必需 claims：

| Claim | 要求 |
| --- | --- |
| `iss` | 与 `issuer` 精确匹配 |
| `aud` | 与 `audience` 匹配 |
| `exp` | 在未来 |
| `client_id` | 非空 |
| `scope` | 存在 |
| `nbf` | 可选；不能晚于当前时间 |

`identity_kind = "subject"` 时要求 `sub` claim；`identity_kind = "client_id"` 时改为映射该 claim。

Scope 包括 `bots:list`、`messages:read` 和 `messages:send`。Scope 本身不授予任何资源访问权——每次消息操作还必须匹配一条精确的 Resource grant。

## 可用工具与资源

| 类型 | 标识 |
| --- | --- |
| Tool | `bots.list` |
| Tool | `messages.list_recent` |
| Tool | `messages.send` |
| Resource | `lingchu://server/info` |
| Resource | `lingchu://bots/{platform_id}/{adapter_id}/{protocol_id}/{bot_id}` |

读取要求持久化的读取前审计。发送要求持久化的发送前审计、平台调用前立即复查授权及结果后审计。可能已经投递的超时返回 `uncertain`。支持保持顺序的文本和公网 HTTPS 图片，并拒绝不安全下载目标。
