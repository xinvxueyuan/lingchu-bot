## See it in action

```text title="QQ group management — sample commands (en_US locale)"
menu                        # list available submenus
member-management           # member management submenu
mute @user 10m              # mute a member for 10 minutes
mass-announcement <content> all  # broadcast announcement to all groups
restart-protocol-endpoint   # restart the OneBot V11 protocol endpoint
```

## Current capabilities

<ul class="hero-features">
  <li>
    <b>NoneBot2 core</b>
    <span>Plugin entrypoint with declared local plugin directories and adapters.</span>
  </li>
  <li>
    <b>QQ group management</b>
    <span>Mute, member management, announcements, kicks, and group profile updates.</span>
  </li>
  <li>
    <b>OneBot V11 default</b>
    <span>Single active adapter; Milky, QQ, and OneBot V12 are deprecated and removed.</span>
  </li>
  <li>
    <b>Message storage</b>
    <span>Optional event, processing, lifecycle, and API call summary recording.</span>
  </li>
  <li>
    <b>TOML + ORM</b>
    <span>localstore path management and async CRUD helpers across SQLite, PostgreSQL, MySQL, and MariaDB.</span>
  </li>
  <li>
    <b>i18n runtime</b>
    <span>gettext / Babel catalogs for `zh_CN` and `en_US`.</span>
  </li>
  <li>
    <b>Developer tooling</b>
    <span>prek hooks, tests, and CI checks for general commands.</span>
  </li>
  <li>
    <b>Extension room</b>
    <span>Cross-platform and non-group-management features for later iterations.</span>
  </li>
</ul>

<Aside type="caution" title="Project status">

This project is still in pre-alpha / development. Code, configuration, command behavior, and documentation may continue to change. Do not treat the current interfaces as stable production APIs.

</Aside>
